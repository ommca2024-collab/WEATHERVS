# Weather VS India - India's Smart Weather Hub

## Project Overview

Weather VS India is a responsive web application that provides real-time weather information for Indian cities. The application allows users to search for any city in India and view current weather conditions along with a five-day forecast. The project focuses on delivering weather information through a clean, professional and user-friendly interface.

## Features

- Real-time weather data
- Search weather by city
- Five-day weather forecast
- Light and Dark mode
- Responsive design
- Recent searches
- Weather alerts section
- Modern user interface

## Technologies Used

- HTML5
- CSS3
- JavaScript
- OpenWeather API

## Prompts Used During Development

### 1. Project Design Prompt (ChatGPT and Deep Seek)

Design a professional weather application with light and dark mode. Improve the user interface using modern CSS techniques. Generate responsive layouts for mobile and desktop devices. Optimise JavaScript code for weather API integration. Deep Seek AI was then used to generate the complete initial code structure.

### 2. Project Enhancement Prompt (Claude)

Weather VS India – India's Smart Weather Hub is an existing API-based weather application with a fully functional API integration already configured in the JavaScript file. The API key, file structure, existing functionality and all current connections must remain unchanged while the entire user interface and user experience are redesigned into a modern, professional and portfolio-ready product.

The application should feature a dedicated landing page containing a welcome animation, an attractive hero section, a professional city search bar, recent searches, suggested Indian cities and intelligent weather alerts. The design should incorporate modern typography, glassmorphism effects, elegant shadows, smooth transitions and fully responsive layouts to provide a polished and engaging user experience across mobile, tablet and desktop devices.

After a city is searched, users should be directed to a dedicated weather dashboard displaying current weather conditions, temperature, humidity, wind speed, feels-like temperature, UV index, visibility, pressure, sunrise, sunset, weather alerts, air quality and a five-day forecast wherever supported by the API.

Both light and dark modes should be significantly enhanced with improved readability, premium styling and seamless theme transitions. Professional animations, hover effects, loading states and weather-based visual enhancements should be implemented throughout the application.

The UV index section must be fixed and weather alerts should provide meaningful recommendations. The website should use British English, avoid emojis, include a professional weather-themed favicon and display an elegant footer stating "Created with Love by Om Kute". The final solution must be error-free, highly responsive, visually impressive and suitable for professional project submission.

## Demonstration

### Project Functionality

Weather VS India allows users to search for any Indian city and view real-time weather information along with a five-day forecast. The application displays temperature, humidity, wind speed, visibility, pressure and other important weather details through a clean and responsive interface. Users can also switch between Light Mode and Dark Mode for an enhanced viewing experience.

### Code Structure

The project is organised using separate files for structure, styling and functionality:

- `index.html` – Contains the user interface and page structure.
- `style.css` – Handles styling, themes, responsiveness and animations.
- `script.js` – Manages API requests, weather data processing and dynamic content updates.

This separation improves maintainability, readability and scalability of the project.
